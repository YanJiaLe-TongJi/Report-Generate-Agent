使用说明

第一次使用

  1. 打开模型设置，选择写作服务商，填写 API Key 并测试连接；有图片资料时还需设置图片识别模型。
  2. 按实验大类选择具体实验，或填写大类和实验名称，一次上传多张图片保存为资料组。再导入自己的 Excel/CSV 数据或原始记录。
  3. 填写封面信息并生成报告。完成后点击文件名，选择保存位置。
  4. 在报告记录中填写修订要求，生成新版本；旧版本保留。

原始记录图片

仅提供记录图片时，先生成 Excel 确认表。保存、核对并修改后，重新导入该表格，勾选它并点击原任务的“使用选中数据继续”。同时提供表格与记录图片时，以表格为数据来源，图片作为附录。

版本与模型

Word 轻量版导出 DOCX；完整版额外导出 PDF 和含图片资源的 LaTeX 源码包。生成 DOCX 不需要安装 Office。模型 API 调用需要网络与账户额度；App 不提供免费 API Key。DeepSeek 和 MiniMax 的预设写作模型不用于图片识别，请另选 Kimi、Qwen、GLM 的视觉模型或自定义视觉接口。

本地保存与异常处理

Windows 数据位于本机用户的 AppData\Local\PhysicsReport；macOS 位于 ~/Library/Application Support/PhysicsReport。完整备份该目录可保存资料和报告，但 API Key 需在新电脑重新设置。退出会停止运行中的任务，重启后可重新生成；已完成报告可以继续修订。编译失败时可保存原文、源码包和日志。

连接失败请检查接口地址、模型 ID、密钥、网络与账户额度。自定义服务使用 OpenAI Chat Completions 格式，地址填写至 /v1 等接口根目录，不填 /chat/completions。API Key 留空表示继续使用该接口已保存的密钥。
