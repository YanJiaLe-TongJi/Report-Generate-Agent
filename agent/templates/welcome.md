# 欢迎使用物理实验报告生成器

这是帮助整理物理实验资料、数据和报告格式的工具，支持 Word 与 PDF。生成内容需自行检查，实验数据应来自真实测量。

## 1. 配置模型

网站支持 **DeepSeek、Kimi、Qwen、MiniMax、GLM**，也可填写自定义 OpenAI 兼容接口。

1. 在「模型设置」选择写作服务商，确认 Base URL 和模型 ID，填写该平台的 API Key。
2. **多模态模型**直接共用一套配置处理写作与图片；**纯文本模型**需要另外选择支持图片的视觉模型，可跨服务商搭配。
3. 点击「测试连接」。多模态模型会同时测试图片识别；独立视觉配置使用「测试图片识别」。测试会产生少量模型调用费用。
4. 点击「保存到账户」。之后密钥留空可沿用已保存的配置；更换服务商或接口地址需重新输入密钥。

Kimi 的可用模型目录每 24 小时从官方文档同步，页面显示最近成功时间。K2.5、Moonshot V1 已下线。当前可选择 K3 或 K2.6 等目录内模型；K3 需按 Kimi 平台要求充值开通，免费赠送额度不代表已获得 K3 使用权限。其他服务商预设允许手动修改，以平台实际开通模型为准。

平台入口：
- Kimi：https://platform.kimi.com
- DeepSeek：https://platform.deepseek.com
- Qwen：https://bailian.console.aliyun.com
- MiniMax：https://platform.minimaxi.com
- GLM：https://open.bigmodel.cn

密钥通过 HTTPS 传到本站，在服务器使用 AES-GCM 加密保存，不会回填到网页或浏览器本地存储。生成时服务器需解密并调用所选模型平台；拥有服务器和加密密钥访问权限的维护者仍可能读取，不能视为端到端加密。请妥善保管密钥，也可在对应平台撤销。

## 2. 选择实验和上传资料

- 系统资料库按「实验大类 → 具体实验」选择，也可自行上传实验资料图片。
- 上传 Excel 实验数据，可附原始记录图片作为附录。
- 只有原始记录图片而没有数据表时，先识别并下载 Excel 确认表，核对修正后重新上传，再生成完整报告。
- 参考 Word/PDF 样例为可选项；已保存的样例可再次选择。
- 框架模式可不上传数据，数据处理部分保留公式和空表格，不会编造测量值。

## 3. 生成、下载与修订

填写封面信息并选择 Word 或 PDF，点击「生成报告」，查看进度。完成后及时下载结果，可以输入自然语言要求修订章节。临时文件会按服务器清理策略删除，不要将网站作为长期文件备份。

## 常见问题

- **模型不存在或已下线（404）**：刷新网页选择可用模型，或核对自定义模型 ID。
- **密钥无效（401）**：核对服务商、接口地址和密钥是否对应。
- **无权限（403）**：检查模型是否开通、是否需要充值。
- **限流或额度不足（429）**：检查余额并稍后重试。
- **无法识别图片**：使用支持视觉的模型，先做图片测试；检查图片清晰度和大小。
- **连接超时**：稍后重试或换用已开通的其他服务商。失败会显示错误，不会静默跳过识别。
- **公式、计算或排版有误**：检查数据与模型输出，通过修订或手动编辑修正，提交前自行确认。

问题可通过页面顶部「问题反馈」提交。
