# 欢迎使用物理实验报告生成器

## 这是什么

还在为枯燥重复的物理实验报告烦恼吗？那这正是你所需要的！

这是一个帮助同济大学学生成物理实验报告的工具。它使用 Kimi AI 来自动识别实验资料、分析数据并生成格式规范的 LaTeX 报告。

搭建动机是作者本人上学期写物理报告深感赤石，纯粹的机械劳动，学校给的模板还是是word，插入公式要一个一个手点，遂在假期萌生了把模板迁移到tex上并搭个agent帮我写的念头，最终有了本项目。

此项目几乎是纯Vibe Coding产物，"Code is cheap，show me your prompt."

主要功能：
- 上传实验资料图片，AI 自动提取实验原理和步骤
- 上传实验数据表格，AI 自动进行数据处理和计算
- 使用系统实验库一键生成（如果有管理员上传的资料）
- 生成符合学校格式的 PDF 报告

## 如何使用

### 第一步：申请 Kimi API Key

这个工具需要调用 Kimi AI 的接口，所以你需要先申请一个 API Key。

**官方平台：**
- 官网地址：https://platform.moonshot.cn
- 控制台地址：https://platform.moonshot.cn/console/api-keys
- API 文档：https://platform.moonshot.cn/docs

**申请步骤：**

1. **注册登录**
   - 访问 https://platform.moonshot.cn
   - 使用手机号注册账号
   - 新用户会自动获得 15 元免费额度

2. **创建 API Key**
   - 登录后点击左侧"API Key 管理"
   - 点击右上角"新建"按钮
   - 输入名称（如"实验报告"）
   - 点击创建

3. **保存 Key**
   - 创建后会显示完整的 API Key（格式：sk-xxxxxxxx）
   - **重要：** 这个 Key 只显示一次，请立即复制保存
   - 如果丢失，只能删除重新创建

### 第二步：在系统中使用

1. **设置 API Key**
   - 在本页面"API Key 管理"处输入你的 Key
   - 点击保存，系统会自动加密存储

2. **选择实验**
   - 如果有管理员上传的系统实验，可以直接在下拉框选择
   - 或者手动填写实验名称和封面信息

3. **上传文件**
   - **实验资料**：实验指导书的图片（JPG/PNG）
   - **实验数据**：你自己的实验数据表格（Excel）
   - **参考样例**（可选）：上传之前写得好报告，帮助 AI 学习格式

4. **生成报告**
   - 点击"生成报告"按钮
   - 等待 1-3 分钟
   - 下载 PDF 文件

## 重要提示

### 关于 API Key 安全

- 你的 API Key 会在浏览器中加密后才发送到服务器存储
- 系统管理员无法直接看到你的明文 Key
- **建议：** 如果担心安全，每次使用后点击"清除"按钮删除 Key
- 你也可以在 Kimi 官方平台随时删除或重新生成 Key

### 免责声明

1. **内容准确性**：AI 生成的内容可能存在错误，特别是公式计算部分。**请务必自己检查一遍再提交**，不要直接复制使用。

2. **学术诚信**：这个工具只是辅助，帮助你整理格式和提取信息。实验数据必须是自己的真实数据，数据处理也要自己理解。请不要用它来造假或抄袭。

3. **API Key 安全**：虽然系统已采取加密措施，但如果你的 Key 泄露（比如别人看到你的屏幕），我不负责任。请保管好自己的 Key。

4. **服务可用性**：这是一个学习项目，可能偶尔维护或出故障。建议不要拖到最后一天才写报告。

## 常见问题
**Q：生成的模板和原来的word一样吗？** 
A:模板的tex文件是我人工迁移的，几乎无差别。但latex编译的pdf排版天然和word转的不太一样，我觉得没关系，如果有顾虑我依旧提供word版下载，但质量可能差于latex。

**Q：编译的pdf内容有问题该怎么修改？** 
A：pdf有问题可以反馈给模型让它按要求修改，但可能有些问题只能人工修改编译。

**Q：生成报告需要多久？**  
A：一般 1-3 分钟，取决于你上传的图片数量和网络情况。

**Q：生成的报告可以直接交吗？**  
A：**不建议**。AI 生成的内容可能有错误，特别是公式和数据处理部分。建议作为参考，自己检查修改后再提交。

**Q：15 元额度够用吗？**  
A：够用。新用户的 15 元免费额度大约可以生成 30 份报告。

**Q：我的 API Key 安全吗？**  
A：系统会在你的浏览器里加密 Key 后再存储，管理员看不到明文。但建议每次使用后清除，或定期在官方平台更换 Key。

**Q：为什么识别效果不好？**  
A：请确保上传的图片清晰、文字清楚。手写内容识别效果可能不好。
